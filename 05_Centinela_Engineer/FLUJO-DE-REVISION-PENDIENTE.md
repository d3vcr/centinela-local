# Centinela Engineer — flujo de revisión pendiente

Flujo propuesto para CEN-08:

1. validar autorización, repositorio, rama, HEAD y limpieza;
2. reunir evidencia y localizar la primera divergencia;
3. definir un cambio mínimo y su rollback;
4. escribir prueba junto con el cambio;
5. ejecutar validación local selectiva;
6. revisar diff y secretos;
7. presentar propuesta humana;
8. commit o PR únicamente con autorización;
9. despliegue fuera de Centinela.

Pendiente definir contratos, herramientas, límites de escritura y política de
retención.
