# CEN-00 — Condiciones de detención

Detener y no cerrar la fase ante:

- fuente crítica faltante;
- contradicción de seguridad;
- secreto real no saneado;
- procedencia o hash no determinable;
- sustitución de un original por archivo similar;
- aparición de código o artefactos operativos;
- necesidad de SSH, Internet, Pi, SQLite, MQTT o despliegue;
- cambio previo no atribuido que se solape;
- intento de iniciar CEN-01.

Condiciones activas al 2026-07-30:

- informe Mac faltante;
- imagen original faltante;
- Fase I sin commit propio;
- vigencia runtime no verificada;
- fuente dedicada V3-06 faltante.
