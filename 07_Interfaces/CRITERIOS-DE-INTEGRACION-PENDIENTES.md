# Interfaces — criterios pendientes

- API local, loopback y métodos de consulta;
- contrato explícito de frescura, fuente y estado;
- degradación segura si Centinela cae;
- no interferir con puertos NEXO;
- `null` no se convierte en cero;
- `stale`, `offline` y `SIN SEÑAL` permanecen visibles;
- evidencia accesible por hallazgo;
- ninguna acción administrativa en la misma superficie inicial;
- voz sin capacidad de autorizar acciones.
